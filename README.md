# CyberQuest – The Compromised Office

A VR cybersecurity-awareness game for Meta Quest (Unity 6, URP, Meta XR SDK). You're the last employee in the
office from 5:45 to 6:30 PM; six attacks and one genuine colleague request arrive one at a time, and your choices
decide the ending.

## Getting it running on a new machine

1. **Install Unity 6000.6.6f1** through Unity Hub (exact version), with **Android Build Support**
   (OpenJDK + Android SDK & NDK) if you want to build for Quest.
2. **Clone** this repo and open the folder in Unity Hub (`Add > Add project from disk`).
   The first open takes several minutes: Unity downloads the packages listed in `Packages/manifest.json`
   (including the Meta XR SDK from Meta's registry) and rebuilds the `Library/` folder, which is not in git.
3. To play without a headset, install **[Meta XR Simulator](https://developers.meta.com/horizon/develop/unity/)**.
4. In Unity: `CyberQuest > 2. Build Office Scene` (regenerates the scene), then
   `CyberQuest > 5. Play in Meta XR Simulator`.
5. To build for Quest: `CyberQuest > 1. Configure Project for Quest`, then `CyberQuest > 3. Build APK`
   (output goes to `Builds/`, which is not in git).

## Editing

Everything in the office is generated by code: the scene builder is
`Assets/_Project/Scripts/Editor/OfficeSceneBuilder.cs`, gameplay is in `Assets/_Project/Scripts/`.
Change code, then run `CyberQuest > 2. Build Office Scene` again — don't hand-edit the scene, it is overwritten.

Simulator keys: look = right-mouse drag or arrows · move = WASD · press button = T · grab = U ·
teleport = hold Y then release · turn = G / J. Turn on *Point & click* in the simulator so the ray follows the mouse.
